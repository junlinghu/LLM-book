# code: Tokenizer

Notebooks for the worked examples and appendix labs in Chapter 5 (Sections 5.1–5.10), including the byte-level BPE tokenizer built in Section 5.10. Each listing in [`chapters/05-tokenizer/`](../../chapters/05-tokenizer/) links to a notebook in this folder.

Prose stays in the chapter. Dependencies vary by section: the standard library, `regex`, `tiktoken`, Hugging Face `transformers` / `tokenizers`, `sentencepiece`, and `huggingface_hub`. Several notebooks download tiny Shakespeare or a pretrained tokenizer the first time they run.
